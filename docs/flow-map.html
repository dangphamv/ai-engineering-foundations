ai-engineering-foundations · week 1

Sơ đồ flow: chạy gì, theo thứ tự nào, dùng công cụ gì

Bấm vào từng node trong sơ đồ để xem node đó làm gì, dùng thư viện nào, kỹ thuật gì và chuyện gì xảy ra nếu bỏ nó đi.

Bạn làm gì trước

Hai file độc lập, không phụ thuộc nhau. Nên chạy train.py trước vì không cần key và không tốn tiền.

Bước 0 · 1 lần

Cài thư viện

uv sync

uv đọc uv.lock và tạo .venv giống hệt máy gốc.

Bước 1

Train mạng nhỏ miễn phí

uv run week1/train.py

Chạy trên CPU vài giây. Chạy được là môi trường đã ổn.

Bước 2

Điền API key

cp .env.example .env

Mở .env, thay sk-... bằng key OpenAI thật.

Bước 3

Gọi LLM tốn vài cent

uv run week1/sentiment.py

Cần internet. Lỗi lúc này gần như chắc chắn do key hoặc credit.

Bước 4

Thí nghiệm

Sửa một chỗ trong code, chạy lại, so kết quả. Mỗi node bên dưới có mục “Nếu bỏ đi” gợi ý chỗ để thử.

Flow bên trong từng file

Input: 6 câu review. Output: mỗi câu một nhãn positive / negative / neutral + confidence. Thời gian chờ mạng chiếm gần hết, nên dùng async để 6 request chạy đồng thời trên 1 thread.

Mô phỏng MAX_CONCURRENCY

6 request, mỗi request mất 0.9–1.5 giây chờ mạng

Input: 2000 điểm 2D có nhãn 0/1 (hai hình trăng lồng nhau). Output: một model đoán đúng ~95.5% trên dữ liệu chưa thấy. 50 epoch × 25 batch = 1250 lần cập nhật trọng số.
